Your streaming toolkit

Type your channel names below and chat starts working — no account needed for Twitch or Kick. Then drop the overlay into OBS. Leave the black terminal window open while you stream.

Setup Chat overlay style Alerts style Stats bar style

Chat overlay

Copy this link and add it to OBS as a Browser Source.

Change how it looks
In OBS: Sources → + → Browser → paste the link → set Width 400 and Height 1080 → OK.

Alerts overlay

Follows, subs, tips and raids from every channel, one at a time. Add as a second Browser Source.

Change how it looks
Set Width 1920 and Height 1080 (full screen) and let the style page decide where on the screen alerts appear. Alerts need a channel to be signed in — chat works without, alerts don't.

Stats bar

Viewers across all platforms, time live, this stream's follows and subs, and a goal bar.

Change how it looks
Set Width 1920 and Height 90. Viewer counts need a channel to be signed in; follows and subs count from when the overlay opened.
