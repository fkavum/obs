Rehearsal

A pretend stream, so you can see everything working before you go live. This drives the real toolkit — the same overlays, the same chat commands — so whatever happens here is what will happen on stream.

Each overlay is trimmed to the part it is actually drawing, so the ones underneath show through — browsers paint every embedded frame on solid white, and there is no way to ask for a see-through one. OBS has no such limit: on stream the layers are genuinely transparent. Use this to check placement and readability, not to judge edges and soft shadows.
