What you can type in your own chat

!task add tidy the deskPut something on the list
!task done 2Tick task 2
!task undone 2Untick it again
!task move 3 1Make task 3 the first one
!task edit 2 the new wordingReword task 2
!task remove 2Take task 2 off
!task clear doneClear the finished ones (clear all, clear chat)
!task chat onThe switch above, from chat

Only you can use these — the toolkit goes by the channel-owner badge your platform puts on your messages, so nobody else can run your list.
